Data
====

No corpus ships here, bar a 3200-record ASRS sample (public domain). All six corpora are
public; here is where each lives, on what terms, and how the streams were built. Commands
run from paper/.

Sources
-------

ASRS          NASA Aviation Safety Reporting System, https://asrs.arc.nasa.gov/search/database.html.
              US government work, public domain; voluntarily reported, de-identified, not a
              probability sample. No bulk download: the web form exports CSV, 5000 records a
              query. Our export (August 2026): 77 files, January 1988 to June 2026, fields
              Time/Date, Events/Anomaly and Report 1/Narrative.
HuffPost      News Category Dataset v3, Misra (2022), Kaggle, CC0. 209527 records.
arXiv         Hugging Face bluuebunny/arxiv_metadata_by_year, 34 parquet files; metadata CC0.
Amazon        Amazon Reviews 2023, CDs and Vinyl, Hugging Face McAuley-Lab/Amazon-Reviews-2023;
              research use, check the terms before redistributing.
MultiEURLEX   Chalkidis et al. (2021), English, EUROVOC level 1, Hugging Face
              coastalcph/multi_eurlex, CC-BY-4.0.
PubMed        NLM PubMed 2026 annual baseline with MeSH 2026,
              https://ftp.ncbi.nlm.nih.gov/pubmed/baseline/; NLM terms and conditions. English
              journal articles indexed in MEDLINE, published 1995 to 2010, 76080 records, 13
              top-level MeSH categories. Its stream builder is not in this repository.
GloVe         glove.6B.200d, Stanford NLP, PDDL 1.0.
DistilBERT    distilbert-base-uncased, Hugging Face, Apache 2.0. No weights ship.

Layout
------

The trainers read embeddings from ../embeddings and the arXiv and Amazon builders read
../data_external/prospective (both beside paper/), so fetch into those:

    EXTERNAL_DIR=../data_external/prospective EMB_DIR=../embeddings python scripts/fetch_data.py
    python scripts/check_data_layout.py      # what is there, what is missing (same variables)

ASRS (--data-dir of build_streams.py; ASRS_DIR for the check) and HuffPost (--raw) are manual;
MultiEURLEX goes to data_eurlex/en_all_level1.parquet. DOMAIN_EMB points the trainers at the
ASRS corpus embeddings if they live elsewhere.

Building the streams
--------------------

    python scripts/build_streams.py --data-dir ../data_asrs --stream primary    # 2010-2025
    python scripts/build_streams.py --data-dir ../data_asrs --stream secondary  # 1999-2008
    python scripts/build_huffpost.py --raw data/external/huffpost.json
    python scripts/build_arxiv_amazon.py                    # prints its label-schema check first
    python scripts/build_multieurlex.py                     # 1988-2014, 12 labels
    python scripts/build_prior_shift.py, build_vocabulary.py, build_vocabulary_perm.py,
           build_construction_seeds.py, build_factorial.py  # the constructed drifts
    python scripts/train_embedding.py                       # corpus embeddings (word2vec), pre-2010 ASRS

Every stream built here: records in time order, MinHash near-duplicate removal (earliest kept), 8
contiguous periods of equal size, a 20% test split under data seed 20260802, labels with at
least 75 test positives in every period (HuffPost is the exception; its builder says why). The
2009 ASRS narrative change (abbreviated to expanded text) falls outside every stream, and
the half year of 2026 is left out.

Shipped metadata
----------------

streams/periods_*.json       period boundaries, spans, counts, duplicates dropped, data seed
streams/labelset_*.json      the labels that passed the positives rule, with their support
streams/eurlex_*.json        the MultiEURLEX window check and build summary
streams/external_streams.json, jsd_adjacent_years.csv, asrs_abbrev_decode.json
                             benchmark windows, the adjacent-year divergence behind the 2009
                             break, the abbreviation expansion used across it
streams/stream_sample.parquet  400 ASRS records per period: a smoke test of the training
                             harness (python scripts/train_sequential.py --stream sample
                             --condition C2 --seed 0), never a result

Rebuild notes
-------------

The ASRS streams rebuild record for record. HuffPost gives 34863 records against the paper's
34805 (same labels and period boundaries); the shipped results use the original stream.
Its near-duplicate step uses Python's salted hash(), so fix PYTHONHASHSEED for repeatable
runs. The arXiv cs subcategories stream was built inline and has no builder here. Seeds 0 to 7
of the first BiGRU runs ran on Apple MPS and seeds 8 and 9 on CPU, so agreement across
devices is statistical, not bitwise.
